## Metrics Definition

| Metric | Definition |
|---|---|
| Match rate | % of passenger requests matched to at least 1 trip |
| Avg detour | Average extra km added to rider's route per booking |
| Avg wait | Average time between request and booking confirmation |
| Seats filled | Average % of available seats booked per trip |
| Top-3 acceptance | % of accepted bookings where the chosen trip was in top 3 results |
| AUC | Area under ROC curve for the learned ranking model |
